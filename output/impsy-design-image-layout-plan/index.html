IMPSY Design Image Layout Plan

Skills Applied

  • ux-researcher-designer: used for grouping the images by user/design purpose rather than by file folder alone.
  • ui-design-system: used for the responsive grid choice and compact component-like figure treatment.
  • markdown-html/design-system: used only as a lightweight reminder to preserve readable typography, contrast, and scannable document structure.

Layout Decision

Use /projects/impsy-interface/gallery/ as the visual archive, not the process page. The process page should remain a readable story and link to the gallery when visitors want the fuller set.

Gallery sections:

  1. Design process: Double Diamond, paper wireframe, Figma prototype, interaction flow.
  2. User story maps: three original story maps shown in a compact grid.
  3. Original workflow: old IMPSY screens grouped as the baseline that motivated the redesign.
  4. Redesigned interface screens: full new-interface screenshot set shown as a responsive archive grid.
  5. System and context: system design, dataflow, final teaser, and hardware setup.

Public-Safety Boundary

Included:

  • thesis design-process diagrams
  • story maps
  • old and new interface screenshots
  • system/context diagrams and existing public NIME assets

Still excluded by default:

  • ethics, consent, recruitment, and participant documents
  • raw study data, interview material, private feedback PDFs, and appendix material
  • thesis PDF publication until Kevin explicitly approves it

Follow-Up Checks

  • Verify the gallery on desktop and mobile after build.
  • Confirm the screenshot grids do not feel too dense on the live page.
  • If the old workflow screenshots feel too sensitive or too technical, replace them with a single contact-sheet style image or cropped/redacted variants.
