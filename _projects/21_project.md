I completed this coursework for COMP1730 (Programming for Scientists) at ANU in
Semester 1, 2021. This was my first ANU programming unit, aimed at students from
non-CS backgrounds, and it builds Python fundamentals around practical data-driven
problems rather than abstract exercises.

The capstone project assignment asked for a self-contained Python program built around
a real-world dataset: daily COVID-19 case data across many regions over an extended
period. The brief was open enough to require designing the program's structure myself,
deciding how to load, process, and present time-series data, and writing up the
reasoning behind those design choices in an accompanying report.

The code for this is kept private (it's still an active ANU assignment), but here's
what it involved: writing Python from scratch to parse and process a large multi-file
dataset, structuring the program into clear functions rather than one long script, and
producing some form of summary or analysis output that made the underlying data easier
to interpret.

The hardest part, looking back, was simply structuring a program of any real size for
the first time. Up to that point I had mostly written short, self-contained exercises;
this was the first time I had to think about decomposing a problem into functions,
handling messy real-world data (missing values, inconsistent formatting across daily
files), and keeping the whole thing readable. It was a small project by later standards,
but it was the first time programming felt like building something rather than just
solving a puzzle.
