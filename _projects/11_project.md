I completed this coursework for COMP3600 (Algorithms) at ANU in Semester 2, 2023. The
unit is one of the core theory units in the degree, focused on designing correct and
efficient algorithms and being able to formally argue about their correctness and
running time, rather than just getting code to pass test cases.

The unit had two assignments. The first was a written assignment covering algorithm
design and analysis questions: working through problems that required choosing an
appropriate algorithmic strategy (e.g. greedy, divide-and-conquer, or dynamic
programming style reasoning) and justifying why it was correct and what its complexity
was. The second moved into implementation, written in C++, where I had to translate a
design into working, efficient code and validate it against a provided test suite.

The code for this is kept private (it's still an active ANU assignment), but here's
what it involved: formal proofs of correctness and complexity analysis on paper, and a
C++ implementation that had to meet both correctness and performance constraints
against hidden test cases.

The hardest part was the gap between "an algorithm that works" and "an algorithm that
is provably correct and within the required complexity bound." It is easy to write code
that passes a handful of test cases by coincidence; it is harder to prove that an
approach is correct for all valid inputs and to reason rigorously about worst-case
behaviour. That discipline of justifying a solution formally, not just empirically, is
the main thing I carried out of this unit.
